# AI-Eye-Tracker-

This is an AI-powered tracking project built using Python, OpenCV and MediaPipe.

It will be the starting point of my journey in learning about AI and coding from scratch.

## Projected Features
- Detect human face
- Detect and track both eyes
- Detect iris position
- Detect blinks


## Goals of Project
- Learn and get more proficient in Python programming
- Learn about AI models and how to use them
